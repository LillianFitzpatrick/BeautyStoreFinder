# BeautyStoreFinder
Developed by Lillian Fitzpatrick (20102189).
BeautyStoreFinder is an Android application developed in Kotlin for organising and managing favourite beauty and skincare stores.

## Features

- Add, view, edit and delete beauty stores.
- Search stores by name or beauty brand.
- Select store categories using a dropdown menu.
- Record descriptions, beauty brands, addresses, website URLs and coordinates.
- Navigate between screens using a cream/pink themed interface.

## Technologies Used

- Kotlin
- Android Studio
- XML layouts
- RecyclerView, CardView, Spinner and SearchView
- Git and GitHub

## How to Run

1. Clone this repository.
2. Open the project in Android Studio. 
3. Allow Gradle to sync. 
4. Run the app on an Android Emulator or compatible Android Device.

## Data Storage
Beauty stores are stored in memory. Data is not retained after the application process ends.
Persistent data storage is planned for Assignment 2.
